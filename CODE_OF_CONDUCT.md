# Code Of Conduct

Be direct, technical, and respectful. This project discusses automation that
can touch source control, credentials, infrastructure, and review boundaries,
so clarity matters.

Expected behavior:

- assume good faith while asking for concrete evidence;
- keep criticism focused on code, documentation, workflows, and risk;
- avoid publishing private credentials, host details, or sensitive logs;
- respect maintainer decisions about automation labels and merge authority.

Unacceptable behavior includes harassment, personal attacks, doxxing, spam, or
attempts to bypass documented trust boundaries.

Maintainers may edit, hide, lock, or remove comments and issues that make the
project less safe or useful to operate.
